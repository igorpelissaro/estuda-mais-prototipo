# Estuda+ – Protótipo navegável

Protótipo de alta fidelidade do Trabalho III de Interação Humano-Computador (UCS): aplicativo mobile para organização de estudos.

Abra o `index.html` no navegador ou acesse pelo GitHub Pages: https://igorpelissaro.github.io/estuda-mais-prototipo/

- Tarefa 1: cadastrar e priorizar uma atividade acadêmica (menu Atividades → Nova atividade)
- Tarefa 2: criar um planejamento semanal de estudos (menu Planejamento)

Dados fictícios, sem backend: as alterações ficam salvas apenas no navegador. Para voltar ao início, use Ajuda → "Restaurar dados de exemplo". Data da demonstração fixa em 03/12/2026 (dia da apresentação).
